Gambito: third-party components and data
=========================================

Stockfish 19 (WebAssembly build "stockfish.js" by Nathan Rugg, based on Stockfish by the Stockfish developers)
  files:   lib/stockfish-19-lite-single.js, lib/stockfish-19-lite-single.wasm, and lib/sf-embed.js (the same
           two files packed into one script so the site runs when opened from disk; one line of the loader is
           patched so it can read the wasm from an embedded copy)
  licence: GNU GPL v3 (lib/COPYING-stockfish.txt)
  source:  https://github.com/nmrugg/stockfish.js  and  https://github.com/official-stockfish/Stockfish
  note:    if this site is ever published, keep these source links with it (GPL requirement).

chess.js 1.4.0 by Jeff Hlywa
  file:    lib/chess.js (also bundled into app/gambito.js)
  licence: BSD 2-Clause (lib/LICENSE-chessjs.txt)

Gambito's own code: app/src/*.js (source) -> app/gambito.js (generated by site_build.py; edit the source).

Chess pieces: "cburnett" set by Colin M.L. Burnett
  files:   pieces/*.svg
  licence: GPL v2 or later

Nunito font by The Nunito Project Authors
  file:    fonts/Nunito.ttf
  licence: SIL Open Font License 1.1 (fonts/OFL.txt)

Opening names: lichess-org/chess-openings
  licence: CC0 1.0 (public domain); used to name lines in the auto-built courses

Game statistics: aggregated from the chess.com Published-Data API (public game archives, Sep-Oct 2026).
  Only aggregate move frequencies and scores are stored; no usernames are shipped in data/.
